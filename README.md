## 🚀 Sobre o projeto — Santander Bootcamp: Ciência de Dados

Este repositório foi criado para documentar minha jornada de aprendizado durante o **Santander Bootcamp**, realizado por meio da plataforma Digital Innovation One (DIO).

A iniciativa tem como objetivo aprofundar meus conhecimentos na área de Ciência de Dados, explorando conceitos, ferramentas e técnicas utilizadas no processo de análise e interpretação de informações.

Ao longo dessa jornada, serão registrados conteúdos estudados, exercícios, desafios de código e projetos práticos desenvolvidos durante a formação.
